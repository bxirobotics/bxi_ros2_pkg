# bxi_ros2_pkg

## Introduction    
BXI ROS2 Packages & Mujoco environment:[`bxi_ros2_pkg`](https://github.com/bxirobotics/bxi_ros2_pkg)     
Communications with both BXI Robot Hardware & Mujoco Environment are in ROS2 messages.    
This repo is distributed in binary packages.    

### Usage
copy this repo to /opt/bix , active it as a standard ROS2 env.
```
cd /opt/bxi    
git clone https://github.com/bxirobotics/bxi_ros2_pkg.git
# then you have the dir: /opt/bxi/bxi_ros2_pkg
# to active it:
source /opt/bxi/bxi_ros2_pkg/setup.bash
```
